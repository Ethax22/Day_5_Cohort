
# Developer Collaboration Platform

## Description
A collaboration platform for developers to manage projects, tasks, and code discussions.

## Features
- JWT login
- Project creation
- Task boards
- Real-time collaboration
- Premium plans with Razorpay

## User Flow
Login → Create Project → Invite Collaborators → Manage Tasks → Discuss Code

## Tech Stack
Frontend: HTML CSS JS  
Backend:  Your choice
Realtime: WebSockets  
Database: Mongodb/MYSQL
